# MYSQL-Practice
This repository contains MySQL practice queries and database concepts covering joins, aggregations, subqueries, window functions, data manipulation, and performance optimization techniques.


## Topics Covered
- Data Definition (CREATE, ALTER, DROP)
- Data Manipulation (INSERT, UPDATE, DELETE)
- JOIN Operations
- GROUP BY & HAVING
- Subqueries
- Window Functions
- Date & String Functions
- Performance Optimization Basics
